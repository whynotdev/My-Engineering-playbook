# 05 — Project Blueprints

Use these as starting points, not complete production specifications.

## Planned blueprints

- E-commerce
- Learning management system (LMS)
- CRM
- HRMS
- Booking and reservation system
- Hospital management
- File/document portal
- AI-enabled assistant

## Blueprint template

1. Business goals and user roles
2. Functional and non-functional requirements
3. Context diagram
4. Main modules and domain boundaries
5. Data model and key constraints
6. API contracts
7. Authentication and authorization
8. Hosting and deployment
9. Observability and recovery
10. Cost assumptions
11. Risks and decisions
12. MVP vs later phases
