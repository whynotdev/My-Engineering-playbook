# 04 — Architecture Patterns

## Planned patterns

- Layered architecture
- Modular monolith
- Hexagonal / ports-and-adapters architecture
- Clean architecture
- Domain-driven design (DDD)
- Event-driven architecture
- Transactional outbox
- Saga and compensating actions
- CQRS (only when read/write needs justify it)
- Multi-tenancy
- Resilience patterns: timeouts, retries, circuit breakers, bulkheads

For each pattern, document the problem it solves, complexity it introduces, failure modes, testing strategy, and when not to use it.
