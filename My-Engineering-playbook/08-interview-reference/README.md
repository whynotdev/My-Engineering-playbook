# 08 — Interview Reference

Use this section to practise explaining engineering decisions, not merely definitions.

## Question format

For each question, prepare:

1. A concise answer
2. A concrete example
3. Trade-offs and alternatives
4. Failure modes
5. Security and cost implications
6. A follow-up question you would ask in a real design review

## Starter questions

- Why choose a modular monolith over microservices?
- How do you select PostgreSQL indexes?
- How do sessions and JWT access tokens differ?
- How would you design idempotent payment initiation?
- How do you handle database connection pools when scaling replicas?
- How do you make a deployment safe to roll back?
- How would you investigate rising p95 latency?
- When would you introduce Redis or a message broker?
- How do you estimate infrastructure cost?
- What belongs in an architecture decision record?
